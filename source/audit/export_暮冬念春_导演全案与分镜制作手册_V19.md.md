# **二、故事梗概（时间线叙事）**

暮冬与春雨的跨时空对话——少年冬冰絮（YXP）与少女雨绪偏（DBX）的七百日之恋。全片以「双扇木窗」为序：左窗凝结 1119 暮冬之雪，右窗流淌 0401 春雨。

四月一日（0401）球场初遇：男主球衣、女主粉色相机定格命运快门。图书室《暮冬》画册与借阅卡、同桌竖起的 DBX 与 YXP 笔记本，将两人绑进同一张课桌。女主以频谱破译 0411 号绿皮火车铜风铃的 111.9 Hz 正弦波（四次泛音 447.6 Hz），樱花走廊的单反教学、私人放映室的十指紧扣，至 0411 车前递纪念照牵手定情。

盛夏海滨电车的第一次帮放黑包、蔚蓝海岸睁眼双手比心，将甜度推至顶点；深秋银杏木栈道许下粉色洛丽塔心愿后，初冬晚自习的慌忙合电脑、98% 显存报错与午夜手机暗屏落泪，让误会降至冰点。

1119 初雪之夜是全片泪点最高潮：空教室抓起遗落黑包追出、街角透明雨伞撑开的声学庇护——伞下电脑播放的 AI 生日纪念短片第 219 帧，与伞下此刻的真人 100% 跨次元重合（连粉色大衣与白围巾都一模一样），误会冰释；雪夜路灯下双手捧脸拭泪、怀里体温捂热的熊猫套热奶茶完成情感的最终落锚。

庆生与永恒：VIP 走廊右臂搭粉大衣迎出粉白洛丽塔公主裙与双蝴蝶结发带、帝王蟹火锅庆生宴上左手银戒剥虾；次年早春融雪窗边，男主左手托左掌写下「DBX & YXP」；0411 一周年绿皮火车前第三次拎黑包牵手，终幕左雪右樱跨季同框，双色彗星划过苍穹——与开篇 Shot\_006 破窗冲入的彗星苍穹首尾回环。

# **五、双轨生成制式与首尾帧接力工作流**

制式 A（标准轨）：Shot\_001–180，每镜 10.0s（240 帧），预留 5.0s 防尾帧衰减安全余量；拉满 15.0s 时严格执行 10.0–15.0s 满格延展段（第 241–360 帧）作为非线性剪辑转场余量 Handle。

制式 B（满格轨）：Manus15s\_001–120，每镜 15.0s（360 帧）100% 吃满 Manus 单次上限，prompt 已融合双镜全量台词与 360 帧五子镜连续运镜。

首尾帧接力三模式（严禁环路）：

| 模式 | 定义 | 用量 |
| :---- | :---- | :---- |
| **模式 A · 母带首帧直出** | 0.0s 首帧 100% 像素级锚定云端 4K 母带（或 1916×2160 子母带向两侧延展为全出血宽银幕） | 34 镜 |
| **模式 B · 末帧接力续生** | 取上一镜导出的第 240 帧（LastFrame.png）作 0.0s 首帧，实现镜间无缝咬合 | 119 镜 |
| **模式 C · 前导/双锁桥接** | C-前导：0.0s 首帧槽留空，母带挂场景参考槽 Weight=0.65（防提前锁死高潮定格）；C 双锁：首尾帧分别硬锁两张母带（如 Shot\_006 室内窗 → 高空彗星苍穹破窗桥接） | 57 镜 |

# **六、540 子镜与 24fps 帧级卡点体系**

每镜 10.0s 内部切分为 5 个院线级子分镜：Sub-Cut α（起幅定锚 0.0–2.0s / F001–048）、β（铺垫演进 2.0–5.0s / F049–120）、γ（主行动 5.0–8.5s / F121–204）、δ（阻尼稳像落幅 8.5–10.0s / F205–240）、ε（Manus 15s 满格延展 10.0–15.0s / F241–360）。

关键帧锚点严格锁定 F001→F024→F048→F084→F120→F168→F204→F240（15s 满格轨追加 F300→F360）。全片合计 540 个核心叙事子镜，平均 3.33s / 80 帧。

空镜防污染：纯空镜与手部微距镜（27 镜）的 Sub-Cut ε 严禁出现人物与发丝，仅限光学景深呼吸与环境流体粒子（雪晶/雨滴/花瓣/蒸汽）缓流。
